## Suggested workflow
- `main` is protected by habit: work on branches such as `feat/dashboard`, open a Pull Request, have the other student review it.
- Commit messages: `feat: add dashboard layout`, `fix: resolve mobile navbar issue`, `docs: add product assumptions`.
- Both students commit regularly; avoid "update", "final", "test".
